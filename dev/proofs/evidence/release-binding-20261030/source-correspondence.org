* Reuse and extension

POO Flow's tool-grant predicate matches the declared tool and action; its slot
contract explicitly keeps runtime execution outside Scheme. It cannot substitute
for Rust's original plan/encoding/session binding or a durable release record.

BoundOperation.matches checks exact effect/state equality before proof reuse.
AuthorityLedger.check additionally binds the exact effect to the stable instance
ID; consume is a pure transition whose transactionality belongs to the Host.
The existing imported WeaverPolicyBridge changed-effect and per-request
error-free-allow lemmas remain reused. The new Rust capability and local
Quint/Lean release histories extend native host obligations without claiming
that those upstream pure functions implement a transactional queue or transport.
