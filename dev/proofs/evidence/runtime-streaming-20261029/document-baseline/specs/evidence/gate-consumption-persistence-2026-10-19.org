* Checked composition

| Lean declaration | Checked consequence |
|------------------+---------------------|
| projection / base_reachable | Every new event projects into the actual initialized preceding source relation, including original account application |
| reachable_invariant | Seals equal original accepted permits; burns/results bind actual original records; grants/burns are unique |
| covered_root_equals_actual_outcomes | Complete archived root coverage reconstructs all actual semantic outcomes without interpreting absence as unused |
| no_regrant_or_reburn | At most one original grant and burn per key |
| actual_account_application_at_most_once | Inherited actual application count remains at most one |
| sealed_unknown_retains_original_reservation | Original source reservation remains booked across uncertainty |
| confirmation_requires_archived_actual_result | No confirmation lacks its exact independently archived result |
| epoch_monotone / fence_rejects_previously_current_cap | Root generation does not roll back; the previously current cap fails the new epoch guard |
| unresolved_burn_prevents_rebuild | An unarchived burn cannot reopen the full-image recovery profile |
| rebuild_preserves_execution_state | Projection rebuilding does not create caps, pending IO, grants or burns |
| archived_result_has_original_settlement | Archived actual receipt retains canonical key, lineage and original final usage |
| end_to_end_account_conservation | All actual applications remain covered by original shared booked reservations and account capacity |

The historical base authority in these statements is a semantic trace, not an
unmentioned physical gate disk that survives the modeled loss. The actual-owner
premise supplies affine original dispatch and atomic actual effect/receipt.
Original pending IO is not reconstructed from root status. If its final result
cannot be authenticated, Covered stays false and recovery can block forever.
The model cannot recover liveness by assuming an unavailable outcome oracle.
