The native publisher is an explicit owner contract. The proof replaces separate
per-component persistence predicates with one whole-event publication transition;
it does not prove a disk/consensus implementation of that transition. Protected
journal rollback is excluded from the model and remains native qualification.

The account theorems require the actual initialized checkpoint/account prefix and
Safe handoff premise. Unknown-hold preservation additionally quantifies the
original source/reservation binding for every account-ready path. The finite
Quint fixture retains its actual pending hold; it does not fabricate a provider
unknown-usage observation. Local account balances are not substituted by counters.

* Acceptance and limitations

Run [[file:../../../proofs/check_llm_custody_publication.py][the checker]]; inspect [[file:../../../proofs/evidence/llm-custody-publication/commands.json][command receipts]] and [[file:../../../proofs/evidence/llm-custody-publication/receipt.json][final acceptance receipt]].
It compiles the local Lean import closure, prints fifteen new declarations,
typechecks Quint, runs twenty-five new controls and seven exported mutations,
samples nine recovery initializers and regresses the twenty-three preceding
custody controls. The raw full-import typecheck exceeded its unchanged watchdog and is retained as
a timeout. Executed Quint routes use [[file:../../../proofs/evidence/llm-custody-publication/closure-certificate.json][a checked source closure]]: only 308 transitive
=run= declarations are blanked using official parser source spans. All types,
actions and helpers retain identical normalized declaration IR; the current
model and its preceding custody model remain byte-identical, including all
25 + 23 controls. An independent checker verifies all ten source/core hashes
and declaration IRs. Those 308 older tests are not claimed rerun here.

The first closure-printing diagnostic did not preserve all declaration IR and
was rejected. The accepted transformation preserves source bytes outside omitted
run spans; it ignores only parser node IDs and top-level declaration ordering
in its comparison. Effect qualifiers remain part of that comparison. Preliminary
diagnostics are retained separately from acceptance results.

The final leaf-only Lean recheck adds =floor_outcome_atomic= after the complete
import closure compiled; unchanged dependency receipts are retained and the leaf
source hash, compiler log and object are refreshed. It changes no transition or
Quint input.

The Quint boundary begins at the actual prior armed initializer; earlier admission
is reused. Lean explicitly takes an initialized custody prefix before composing
original result and budget properties. The compact Quint event projection and
Lean full-state journal have separate checked properties; no automatic formal
Quint-to-Lean or model-to-native refinement proof is claimed.

Acceptance also requires independently decoded ITFs, fifteen four-artifact rows,
English Org links/export, core D2 validation/render inspection, unchanged historical
byte manifests, unchanged source identities and unchanged dependency pins. Finite
random exploration is not exhaustive model checking. Availability, recovery
liveness, source namespace coverage, native anti-rollback, canonical codecs and
actual IO fault injection remain implementation qualification obligations.
