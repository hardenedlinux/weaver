* Source owners

| Directory | Owner |
|-----------+-------|
| sysml | System allocation, typed ports, requirements and resource bounds |
| proofs/quint | State machines, schedule exploration and negative controls |
| proofs/lean and proofs/cedar | Safety/composition proofs and native premises |
| specs/lean and specs/quint | Specification models used by the verification plan |
| d2 | Source-owned architecture rendering and view declarations |

Git owns models, proof sources, test code, curated fixtures and package locks.
Execution logs, verifier receipts, traces and captured source trees are generated
outputs. Keep them under the ignored =.cache/verification/= hierarchy or as CI
artifacts. They do not belong under =dev= and must not be committed, even when a
reproduction command exists. Historical local captures, when retained, live in
=.cache/verification/evidence/proofs/= and =.cache/verification/evidence/specs/=.
The absence of a local capture is not permission to infer a passing result.

* Runtime and verification

Rust runtime and lightweight client code belongs in =crates=. Scheme/POO and
ASCENT semantics belongs in =scheme=. Go development tooling and the in-process
OpenSysML checks live under =go=; =go/cmd/weaver-dev= is the existing verification
entrypoint. Run it with =go -C go run ./cmd/weaver-dev <suite>=. Package managers
own dependency declarations and incremental builds; verification consumes their
prepared outputs rather than maintaining another version registry.

Quint challenges operational schedules and competing designs. Lean proves
conditional structural and refinement laws. Native tests establish the actual
transport, storage, FFI, cancellation and lifetime boundaries. A model verdict
cannot substitute for a runtime result. Retain failed attempts in local/CI
artifacts and report their scope without copying raw output into source control.

The runtime retains typed mTLS RPC and the opt-in Harness HTTP compatibility
boundary. Protocol fixtures belong with their owning tests; benchmarks belong
to each Rust package's =benches=. Source publication, request admission and final
send remain separate authority boundaries. See =../Project.sysml= and
=../docs/architecture/= for their current allocation.
