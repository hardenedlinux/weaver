Multiple Lean/Quint blobs belong to some source families, producing nineteen
exact artifacts in source-review.json. P12 rejects now greater than expiry;
the Gateway model intentionally uses now strictly less than expiry. This is a
semantic design distinction, not an ABI-equivalence claim.

POO Flow supplies strong original-root, provenance and recovery vocabulary.
It does not currently implement this native enrollment protocol. Cedar remains
Code as Policy over authentic facts; Scheme does not manufacture those facts
from caller-provided key or session strings. No compiled Cedar proof is a
cryptographic first-key certificate. The checked import composition here is the
Weaver predecessor proof chain. Source comparison with C8/C10/C11 identifies
reusable upstream contracts; it does not constitute a new compiled import or
refinement proof of those upstream modules. currentAllows remains an explicit
Cedar/native authentic-facts obligation.

* Lean model and composition
The leaf prints twenty-nine declarations. Natural-number-indexed registries and
inductive Run quantify over arbitrary finite traces and populations; the proof
is not restricted to the two-launch Quint fixture.

- Root retention and root_origin establish independent assignment provenance
  from an empty initial root registry. The enrollment principal is pre-existing;
  its native provisioning/authentication remains an explicit rootAuthorized premise.
- ValidBindings associates each first binding with the exact root, erased-key
  template and verified enrollment/beneficiary/session transcript. It is historical
  provenance, not permission to ignore later source or policy changes.
- Covered associates every predecessor invitation with its retained first binding.
  Joined requires its determining publication outcome. OutcomeBound requires an
  outcome to name an actual exact invitation projection. Their two directions
  catch different split-publication failures.
- Qualified combines these properties. Bind and publication require qualification;
  downstream authority advance also requires it. Inconsistent publication cannot
  be made admissible by refreshing only the predecessor's read permission.
- Blueprint explicitly constrains the target to the original current capability
  scope, previous grant, source parent, issuer epoch/challenge and expiration.
  New publication exposes CanPublish and leaves the entire issuance state unchanged.
- Revoke projects an actual predecessor issuer-epoch advance as well as the outer
  enrollment epoch change, preserving the first key/session and publication records.
  The old ticket epoch therefore cannot match the new issuer epoch.
- composition requires a witness to the actual predecessor Run. The generic edge
  is not a trusted alternative transition relation. Instantiate it with actual
  predecessor Step and one-step Run; no authentication or durability predicate is
  replaced by True.

Financial composition retains initialized caller/publication/custody/account
prefixes, safe handoff and original sourceReady-to-OriginalReady binding premises.
A public-key equality lemma alone proves neither account uniqueness nor a refund.
Unknown original use is explicit and retains its hold. All publication and final
execution constraints remain attached to the original canonical claim.

Qualified is a mathematical image invariant, not a proposed full-registry scan
on the streaming path. The native owner needs a bounded per-launch join certificate
and accepted-prefix qualification tied to the determining CAS. A coherent rollback
can satisfy the pure map equalities; the independent non-rollback floor is still
required. Arbitrary restored maps are not valid initial states for the trace proof.
Nat has no wraparound; bounded native identifiers/revisions/epochs must reject
exhaustion and preserve retired namespace/result records.

* Quint fixture and correspondence limits
The fixture has two canonical launches, independent enrollment keys, beneficiary
keys and bootstrap sessions, with the same Kubernetes workload. The enrolled
principal may sign a different beneficiary key, but it cannot overwrite the
first key already committed. Parent publication approval remains an independent
trusted source fact; this fixture publishes only the predecessor's admitted keys.
That finite assignment oracle is not a general native public-key implementation.
The replacement-root test also encounters a restrictive root whitelist; general
canonical root retention is a Lean property, not evidence of a real database index.

Lean eraseKey preserves a previous capability containing the original proposal.
The Quint ticket carries a separate original root field plus the predecessor grant
scope; Blueprint checks that field against actual source custody. These are stated
semantic projections, not an automatic compiler or ABI refinement theorem.
Native verify and approved values denote authenticated owner outcomes, not client
booleans. Both proofs must authenticate one complete canonical transcript.

The current source has twenty-six ordinary guarded controls, five fault controls
and one additional quarantine control. All thirty-two execute. The actual parent
registration, invitation consumption, proof, custody activation and revocation
actions are retained in the ancestor source and executed by the corresponding
controls. The activated fixture checks the original unknown reservation explicitly.

* Fault traces and the quarantine probe
- Shared identity: insert a first binding whose stored enrollment peer is the old
  shared-workload principal. ValidBindings fails. This is a fabricated binding,
  not evidence that an attacker acquired the intended private key.
- Replaced key: mutate the first key after invitation publication. The old public
  invitation still names the original key; both binding and join checks detect
  the mismatch. No active custody change or provider send is claimed.
- Missing outcome: execute actual predecessor invitation registration without the
  outer determining outcome. Joined fails, even though the parent registry is live.
- Split publication: publish only the outcome while the invitation projection is
  absent. OutcomeBound/Joined fail; an outcome alone is not registration completion.
- Rolled-back binding: erase the first-binding membership while retaining the
  invitation and outcome. Covered/Joined fail; recovery must not reopen this slot.

The quarantine probe first creates a missing-outcome image, then explicitly
refreshes the parent invitation read. Consumption still fails at the new outer
join gate. It checks no ticket issuance, no active incarnation change and retention
of the original unknown hold in the fully defined pre-rejection state; the terminal
failed action has no admitted successor. This detects the gap between merely observing a
broken invariant and actually refusing admission from that image.

Decoded ITF observations check actual parent account/source state as well as the
new registry fields: original unknown hold retained, no new provider source calls,
unchanged floor log and original claim, and no active incarnation change for the
five pending-publication faults. Earlier unrelated spent/application state remains;
zero new provider calls is not a claim of zero historical effects.

* Execution protocol and bounded claims
The initial combined CLI route passed six controls and hit its fixed 55-second
watchdog on the next group. That model was subsequently strengthened with explicit
scope checks; those partial results are historical, not current acceptance.
Compiler diagnostics from draft Lean declarations are also retained and excluded.
A later thirty-one-control pass before the quarantine gate is preserved separately.

The accepted current route uses the installed official load, parse, typecheck and
runTests functions. The full current fourteen-module IR, including every current
run declaration, receives actual type and effect analysis once. Parsing has a
20-second watchdog and type/effect analysis has a separate 55-second watchdog.
The same accepted AST, lookup table and collected definitions are reused without
mutation. Each test group calls official runTests, which constructs a new Evaluator
and RNG; each group has its own 20-second execution watchdog. This removes repeated
parsing/analysis without replacing the evaluator or changing any transition.
The old combined-route timeout remains a timeout; it is not relabeled as passing.
The first quarantine-probe draft tried to inspect successor state after fail(),
which has no admitted successor, and raised QNT502. That failed harness and its
source are preserved. The corrected probe checks the fully defined pre-rejection
state and then ends with the guarded consumption failure.

Installed pipeline/evaluator hashes, model bytes, complete results and an unchanged
IR digest after every group are recorded. All thirteen ancestor non-run declaration
IRs match the sealed parent; the current raw leaf also matches the bundled IR.
Only local import source paths, parser IDs/order and checked top-level lexical depth
normalization differ. No semantic/effect qualifier is stripped.

The thirty-two earlier Lean receipts are reused after source/log/artifact checks.
The predecessor's twenty-three Quint controls have sealed independent passing
receipts, reused by exact source identity rather than claimed as a current rerun.
Current tests are bounded deterministic scenarios, not exhaustive state exploration.
The predecessor's 30-second randomized exploration timeout remains unchanged;
no new randomized pass, fairness, liveness, native crypto, provider exactly-once,
performance result or remote CI is claimed.

* Implementation acceptance obligations
The formal contracts still require independent enrollment-credential provisioning,
authentic producer/root assignment, both signature checks over the exact transcript,
authenticated adapter channel facts, canonical key encoding, durable atomic commits,
complete-prefix restoration, anti-rollback floors covering the outer enrollment commit prefix (not merely
the unchanged source/account floor), bounded counter exhaustion and
real final-send refinement. Equality checks do not supply these obligations.

Possession of the authorized enrollment private key or its signing oracle permits
choices for that logical principal under policy. Shared Kubernetes credentials
alone do not. A party that can relay both authorized signing capabilities and the
bound channel cannot be distinguished as a different physical process by this
model. This design enforces logical execution authority and makes no physical
isolation or hardware claim.
