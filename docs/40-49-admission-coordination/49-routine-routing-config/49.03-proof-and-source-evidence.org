* Lean model and proof boundary
Twenty-four declarations compile without sorryAx. Refines constrains a bound semantic
Normal value to the authentic original root/payload/profile/node/response, preserves every
original capability, strengthens the context requirement, preserves region and narrows the
allowance. lower intersects declared targets with the actual catalog and preserves original
Policy/history/support/region/price functions. eligible_is_narrowed derives original eligibility;
this is not achieved by assuming the entire final security property.

Requirements and candidate lists are arbitrary finite lists. The base router supplies actual
catalog generations, capability support, context/cost bounds and current Policy/history facts.
Same-normal lemmas establish extensional equality of lowered runtime configuration after a
normalization witness is supplied. They do not prove a Scheme interpreter, parser normalization
or complete semantic equivalence of arbitrary Scheme and JSON/YAML programs. The fixture check
compares two actual decoded document examples; Scheme is not executed.

provenance_changes_without_semantic_change constructs distinct source identities with equal
semantic values. Package admission and currentness therefore remain separate predicates.
executionOwner requires native finalPolicyValid, admitted package and currentAtCAS for the
actual dispatch view. Compiler/source closure validity, deterministic supported lowering,
authentic original context and final native currentness remain explicit host obligations.
The model does not implement config publication, a Scheme sandbox or native encoding.

Final dispatch and advice theorems use actual LlmRouting transitions. The original one-admission
and one-response-source bounds remain unchanged, so this profile cannot silently implement a
multi-attempt routine. Telemetry stays outside the hard authorization view. AdmissionBridge
must bind the real original source claim, payload, selected target, wire and step reservation;
the imported cost, shared-account and original-claim results are conditional on that actual
bridge. They do not establish full routine-DAG execution, parallel reservation allocation,
identity recovery, native storage/transport refinement or unknown-usage settlement.

* Quint and finite fixture evidence
Thirty-two deterministic controls execute through the installed official full type/effect
pipeline with fresh evaluators per group and unchanged typed IR. The bundle contains the
complete LlmRouting transition module and current leaf; only the thirty-two parent run
declarations are omitted. Official parsed IR comparison checks all non-run ancestor definitions
and every current raw-leaf definition. Parent tests are identity reuse, not newly rerun controls.

Twenty-eight guarded controls cover accepted surface outputs, typed/closure/publisher admission,
profile/response/root/capability/budget rejection, stronger capability filtering, denied advice,
empty candidates, pinned defaults, current hard withdrawals, metrics, final wire/Policy,
unknown retry and single response source. Four unsafe actions outside step produce counterexamples
for weakened allowance, replaced pinned routine, rewritten wire root and hidden second dispatch.
Decoded traces inspect the actual final config/routing records. These are model observations,
not provider calls, storage qualification or a production router benchmark.

Sixteen finite document-fixture checks compare actual JSON/YAML decoding, validate the declared
three-node acyclic example and single-invocation allowance, and reject duplicates, executable
tags, aliases outside the example profile, wrong scalar types, unknown fields/credentials,
forward/cyclic dependencies, excessive totals, missing Contracts and missing capability needs.
The helper is deliberately an example verifier, not the Gateway's production schema/parser.
The source Scheme block remains illustrative. Registered Type/Contract references, arbitrary
routine composition, conditional/fanout/loop validation and native cross-language lowering need
independent implementation/refinement evidence.

The first Lean draft had a record-update layout error and consequent sorryAx diagnostics;
lean-initial.log is retained and not acceptance evidence. The first Quint draft redefined
select, a reserved built-in, and failed official name resolution; its source/invocation/errors
are retained in draft-reserved-select. Final successful sources and receipts are distinct.
No exhaustive/random exploration, recovery liveness, learned-router quality, native compiler/
provider integration, end-to-end performance or remote CI is claimed.
