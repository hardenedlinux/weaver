This category extends the preceding publication contract. It supplies the caller
and capability boundary that a numeric fence, shared workload identity or cached
permit cannot establish. The scope is an AI Agent Gateway with logical execution
authority; it assumes no physical isolation. Models and counterexamples are
executable design artifacts. No Gateway runtime or dependency pin is changed.
