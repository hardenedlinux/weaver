* Executable admission-only source composition

=AdmissionOnly R signals= requires an actual source transition plus exact signal
equality. The wrapper's background transition uses category-20 =Step= with this
filtered source relation. This excludes execution-producing source constructors
rather than assuming a Host callback is harmless.

=concreteSignals= is a compiled lens into actual category-18 state: all root
=sends= counters, the complete child-call function and the actual route dispatch
list. =admission_source_has_no_send= projects through category 20, category 19 and
their actual source path, then composes equality along the path. It covers arbitrary
finite admission-plane executions. A weaker or incomplete native footprint would
invalidate the refinement; hidden I/O is not ruled out by counter equality alone.

Admission/source state is distinct from the subsequent executor's local invocation
state. The wrapper ends at final durable queue admission. Provider-offer events
must enter a separate protected execution product, not be replayed as source-result
commit/application. No whole asynchronous source/executor/storage product is claimed.

* Atomic gate and original slot proofs

A permit is registered by actual resolution after a complete join and original
result lookup. Its image, prefix, owner, validation generation and queue revision
are compared again by =Gate= in the enqueue transition itself. That transition
also checks the current worker, actual original operation binding, effective final
Policy, unused operation key, unused canonical slot and durable admission evidence.

=new_admission_has_current_gate= proves every newly persisted admission had that
actual gate and final Policy/scope conditions at its transition. Earlier observed
join success is insufficient. The proof quantifies over atomic modeled transitions;
native serialization of checks and publication remains an explicit implementation
qualification obligation.

Operation and slot tables are monotonic. =original_operation_never_replaced= and
=original_slot_never_replaced= preserve original immutable bodies across source
commits, owner restart/recovery, observations and provider-client retries. The slot is independent
of a new operation key, payload or route. =occupied_slot_blocks_retry= therefore
applies even after a fresh current permit has been issued. Qualified original
manifest validation is still required to reject overlapping or invented ranges.

Final authorization is an explicit =Owner.finalPolicyValid= predicate over the
actual operation, current result state and validation generation. =operationValid=
authenticates original result/claim/profile/domain/range binding. Both must be
implemented from actual Scheme/Cedar inputs and native effects, not client labels.
The durable admission predicate includes key/slot/receipt persistence and recovery.

* Actual broker composition, with bounds

=brokerProjection= maps an absent operation to the actual existing broker initial
state and an admitted operation to its actual accepted state with no invocations.
=ready_broker_initialized= constructs the broker's real consume/persistIntent/accept
transition chain. The abstract consume mirrors the already committed source fact;
it is not another native nonce consumption.

=queue_broker_initialized= provides that initialized history for each original
operation. An actual =BrokerConsumptionQueue.Run= suffix then composes with that
history. =actual_broker_suffix_once= imports its checked per-offset at-most-one
invocation theorem; =actual_broker_unknown_stays_held= imports its actual unknown
hold theorem. Native authentication/fencing is not obtained from the erased
abstract broker owner. Each native suffix must refine the prior current range,
Policy, receipt and immutable manifest gates under the original operation identity.

The wrapper cannot reset an admitted operation to an absent broker cell. A fresh
SDK key cannot create another abstract initial broker for the same canonical slot.
This is the connection missing from a stand-alone invocation counter. The Quint
fixture additionally represents current admission/drain gates and persistent offers;
it does not prove parser, transport, replication or filesystem behavior.

* Implementation acceptance and remaining qualification

Inject a new source commit between join read and final enqueue, including a run
where projections catch up before enqueue. Interleave owner retirement, qualified
recovery, Policy/history publication and concurrent queue inserts at every final
read/CAS boundary. Verify old permits fail and fresh permits retain the original
slot, claim, profile and reservation. Query lost acknowledgments by exact original
operation; never wake an executor from an uncommitted or duplicate admission.

Instrument every SDK/provider/transport invocation. Commit, result application,
resolution and enqueue must record zero provider calls. Try reentrant provider
callbacks, automatic redirect, retry after partial write, stream reconnect and an
old-worker queued callback. Only the separate current original-range executor may
invoke. A failure after a possible offer retains the original unknown outcome.

Test native atomic publication/recovery of the operation row, canonical slot claim
and immutable receipt; a partial write or unavailable result must keep admission
closed. Retain tombstones across snapshot restore/compaction. Full native consensus,
non-rollback storage, canonical codecs, hidden-I/O confinement, scheduling fairness,
settlement, remote exactly-once and performance are outside the checked local scope.
