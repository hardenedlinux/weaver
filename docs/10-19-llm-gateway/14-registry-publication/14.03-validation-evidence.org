* Proof premises and limits

=Safe= preserves intent validity, exact journal-to-intent binding, one original
root publication, certification membership and current active recovery join.
=intent_is_never_replaced= and =journal_cannot_be_replaced= exclude replacement
through any safe transition. =publication_resolves_original_contract= connects
the published original-key lookup to category 13's admitted contract interpretation.
No caller-provided registry view is accepted as that lookup.

=execution_projection= maps every execution-changing transition to an actual
prior model step. Snapshot installation cannot assign execution state. Source
claims, allowance, history-domain bindings, response mode and unknown-usage
settlement constraints follow from that projection. The profile registry does
not independently implement account application or replace the original ledger.

The stable intent, durable journal, immutable object receipts, non-rollback owner
floor and qualified current execution-prefix read are explicit storage/owner
contracts. Local projection loss is modeled separately from authoritative state.
The model does not prove consensus, cryptographic hashing, native fsync, full
byte-range/account interleavings, transport quiescence, provider execution or
liveness. If every trusted log/witness rolls back together, these premises fail;
no successful recovery is claimed for that deployment.

The intent reserves only the original semantic binding and does not issue a send
grant. Certification acknowledges only an exact publication. A later gate joins
the current ledger and fence. Native implementation must enforce this ordering
with authenticated conditional writes; separate stores do not become atomic
merely because the model presents a single transition.

* Runtime acceptance still required

Inject durable-object reply loss, intent-CAS reply loss, root append/confirmation
reply loss and delayed callbacks across owner changes. Restore independently old
object, journal, cache and execution snapshots. Verify exact committed-prefix
membership and current source namespace, with no local-absence fallback. Keep
old queued permits alive and prove they fail the final conditional gate. Restrict
history while refreshing a recovery image; the new image must still deny use.
Preserve unknown holds until attributable terminal/usage reconciliation and the
existing account application protocol completes.

Collect native source-bound receipts and matched latency/memory controls. The
[[file:../../../dev/proofs/evidence/llm-registry-publication/SHA256SUMS][manifest]] seals current artifacts while leaving historical receipts unchanged.
Model verification is not deployed acceptance or a performance result.

* Local validation result

The final runner completed 22 command routes with exit zero: 11 Lean modules,
Quint typechecking, 43 scenario controls (35 guarded cases and eight negative
controls), eight exported counterexample traces, seven bounded sampling routes
and 41 category-13 regression controls. Each sampling route used ten samples
and at most 30 post-initializer steps with seed 167. This is bounded simulation,
not exhaustive temporal verification.

Lean checked 20 printed declarations in the new module without =sorryAx=. The
independent trace decoder checks actual old-permit issuance and the later
authority image, as well as the seven other observable contract violations.
Twelve correspondence rows connect exact Org obligations, passing Quint cases,
printed Lean statements and existing core D2 nodes. Earlier diagnostics are
retained; their failed scenarios are not counted as final acceptance.
