* Scope and reproduction

Run the bounded check runner (retired Python driver). The new [[file:../../../dev/proofs/lean/LlmAuthoritativeScope.lean][Lean module]] imports the actual prior
semantic/child/root models. The [[file:../../../dev/proofs/quint/LlmAuthoritativeScope.qnt][Quint model]] starts from an admitted-root fixture
and checks canonical scope derivation, final use, recovery and settlement races.
The Lean run additionally projects source root setup into GatewayHeadCAS.Run.
Raw commands are in [[file:../../../dev/proofs/evidence/llm-authoritative-scope/commands.json][commands.json]] and final results in [[file:../../../dev/proofs/evidence/llm-authoritative-scope/receipt.json][receipt.json]].

The immutable original-key-to-contract mapping, authenticated root ownership and
canonical source configuration are premises. Root identity cannot be selected
from raw payload equality. Profile publication membership/fork freedom, native
transaction durability, codec/parser correctness and recovery receipt validity
remain runtime qualification obligations. The model does not prove that existing
upstream APIs already implement the new task-profile publication protocol.

* Safety properties and composition boundary

=initialized_audit= checks every accepted use against a derived scope and exact
current image. =uses_keep_registered_record= ties all use records to the single
create-only registration. Domain, response-mode and original-claim results then
follow. =actual_wire_keeps_source_context= binds the existing EncodingBridge to
source-derived budget/history and registry-derived response mode.
=proposal_keeps_source_contract= reuses the semantic trace's actual proposal
validation under that derived scope.

=root_projection= and =child_projection= reuse actual source runs. They retain
original claim uniqueness, shared-account capacity and child allocation bounds.
=allocations_fit_source_allowance= also checks the source allowance link at child
advancement rather than assuming an arbitrarily large routing escrow. Unknown
usage prevents child closure, and the new root-advance guard prevents settlement
state changes before closure. This is a logical charged-state theorem, not an
external financial account application implementation.

The wrapper admits semantic consumption only alongside the actual current
ChildCall and encoding bridge. Semantic disclosure/proposal promotion requires an
actually invoked child and fresh root gate; data-only transitions cannot consume,
release output or add authoritative proposals. The actual semantic transition and
prior typed run carry existing mode/schema/completion/argument requirements.
Native Policy inputs must also align root, route and semantic publication
contexts under one authenticated authority join. Equal numeric revisions from
different namespaces are insufficient. The current owner predicates carry this
qualification; a native Cedar evaluator/adapter alignment proof is not supplied.
The abstraction does not prove byte offsets, every asynchronous range/settlement
store interleaving, provider execution, native JSON validation or liveness.

* Runtime acceptance obligations

Verify authenticated root-to-profile publication, wrong-namespace profile lookup,
identical-input/different-task substitution, missing blobs and stale/split prefix
membership. Test profile-store acknowledgement loss, root CAS reply loss, cache
rebuild and mixed snapshots without changing original bindings. Race head/route
publication and original history restriction against final consume and disclosure.
Recover old workers and queued tickets; verify they cannot re-invoke or replace
response mode. Replay late usage and proposal callbacks against their original
record; keep unknown holds and require fresh tool-effect admission.

Use the existing queue/range/account protocols for transport and settlement
refinement, with matched native controls. Local model proof does not establish
native database atomicity, deployed provider behavior or performance. The
[[file:../../../dev/proofs/evidence/llm-authoritative-scope/SHA256SUMS][manifest]] seals this category and evidence while preserving historical receipts.
