* Lean model, premises and composition

=State= uses total maps with optional rows. A finite run inserts only finitely many
rows; there is no fixed origin/alias bound. Registration changes the origin, family
and claim indexes atomically with the exact decision and actual source transition.
=initialized_coherence= establishes all three indexes agree from the empty initial
registry. =same_family_same_origin= and =same_claim_same_origin= derive uniqueness
from this coherence, rather than assuming unique families as an invariant premise.
Origin and alias map immutability preserve the complete stored entry/target.
=initialized_aliases_bound= separately proves aliases target committed origin rows.

Pending requests retain their exact body. Staging requires same-ID bodies to agree;
commit requires actual pending membership, an unused decision ID and the current
parent/fence. Durable decision identity never changes. Projection loss, recovery
and restart cannot assign source state, remove pending or release exposure. The
recovery predicate is an explicit qualified owner contract, not an executable
implementation of current-prefix authentication.

Every register, bind or consume step requires =SourceStep Request before after=.
The request includes the existing typed recovery cut. =source_projection= gives an
actual admitted source path; =composition= transports any source invariant preserved
by that relation. =canonical_source_composition= explicitly transports that path
into initialized category-18 =Run= when a refinement into its actual =Step= is
provided. Unrelated-origin transitions may stutter in the selected-origin projection;
shared-account mutations still require the joint account guard. This is a concrete typed connection to the existing model, with the
refinement obligation exposed; it does not supply a native multi-origin backend.
Category 18 then supplies original claim/profile/domain/allowance/pending proofs.

For multiple origins, each selected-origin projection must refine its original
initialized source path, while the same joint transition preserves the shared
account/history relation. Cloning independent initial category-18 states does not
satisfy that obligation. The additional shared-pool theorem is a joint admission
bound over arbitrary finite commits, not a proof of a complete asynchronous
multi-account settlement product. Charged exposure never decreases in this model;
there is no settlement, cancellation, delivery or reclamation transition.

=admitted Entry= must authenticate the exact original registration and its family,
claim, profile, budget and history references. =SourceStep= must enforce current
Policy/history, source-cut equality, original grant validity and actual effect
binding, not merely return a successful RPC Boolean. Coherence alone cannot
establish authenticity. A faulty canonicalizer can consistently index the wrong
identity; parser/crypto/producer qualification remains required.

** Storage abstraction boundary

The Lean source value is authoritative state, not a participant snapshot. Its
recovery steps alter visibility/fence only; they do not reconstruct or authenticate
a disk journal. The decision table stores immutable requests, while the native
protocol additionally requires immutable source-result commitments and complete
replay data. Quint's applied-ID set abstracts idempotent participant publication;
it does not execute a storage engine's position/result CAS. Barrier ordering,
result reconstruction and non-rollback prefix qualification remain native
refinement obligations. The models prohibit unsupported recovery rather than
silently assigning arbitrary restored source state.

* Acceptance and evidence boundary

The receipt records tool versions, command counts, source hashes, ITF observations,
Org/D2 checks and unchanged dependency identities. Such metadata stays out of the
core diagram. Native acceptance still requires controlled fault injection at each
journal durability barrier, source/participant CAS, response loss and owner fence;
restoring all permutations of participant snapshots must never create authority.

Test two old/new workers with retained queued requests, late callbacks and historical
receipts; verify only the current broker mutates and exact historical results remain
observable. Exercise at least two genuine origins sharing an account, colliding
qualified families/claims, conflicting alias inserts and concurrent history changes.
Verify the native canonical codec and original source-cut mapping. A passing abstract
model is not a backend atomic-commit, consensus, fsync, native protocol conformance,
remote exactly-once, liveness or performance result.
