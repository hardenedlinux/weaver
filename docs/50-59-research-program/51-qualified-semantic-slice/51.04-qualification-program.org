* Independent admission gates
| Gate | Required evidence | This checkpoint |
|------+-------------------+-----------------|
| Q1 | Common-schema meaning, normal forms and rejection corpus | Specified; native decoders/POO parity pending |
| Q2 | Original task/profile-to-route semantic construction | Lean bridge checked; authentic native publication pending |
| Q3 | Actual provider request/response and SDK effect correspondence | Contract specified; concrete bytes and SDK tests pending |
| Q4 | Durable queue/consumption/writer/usage/account crash recovery | Finite controls checked; native storage/transport pending |
| Q5 | Protocol and routine profile conformance | Bounded profile specified; native conformance pending |
| Q6 | Matched quality/cost/latency/resource evaluation | Evaluation protocol specified; no measurements |

Do not aggregate inherited theorem or control counts into native qualification.
No performance gate may pass by weakening a preceding semantic/fault gate.

* Canonical corpus and independent oracles
Freeze a corpus manifest containing source bytes, admitted task/profile and
knowledge snapshot identities, expected canonical projection/rejection class,
independent golden provider wire, expected response schema and document-ID set,
and authentic usage/unit assumptions. Keep native parsers separate from the
oracle; recomputing expected values with the implementation is not independence.

Configuration vectors: format-equivalent documents; missing/explicit defaults;
duplicate/unknown/null values; number coercion; YAML tags/aliases; unresolved and
forward references; cycles; reordered messages; empty target intersections;
extra requirements; high ceiling with clamped allowance; forged normal allowance;
conflicting profile; missing registry; changed source closure with equal semantics.

Provider vectors: exact role order; retrieval attribution; strict schema support;
rejected lossy features; output/context/tokenizer limits; usage rounding; partial
SSE frame/UTF-8/JSON; oversized fragments; malformed final document; foreign
citation IDs; unrequested tool proposal; redirect and provider-client retry attempts; endpoint
replacement. Do not present a symbolic wire commitment as byte-codec validation.

* Native fault schedule to qualify later
Exercise deciding-store commit before/after reply, crash before/after queue and
consumption, Policy/history publication between observation and CAS, restart with
old worker, old socket/buffer callback, partial write, forged/late usage, competing
terminal seal, account apply lost reply, and snapshot/prefix mismatch. Use actual
process/transport/store fault injection after implementation is authorized.

For each trace retain exact operation IDs, committed deciding events and prefix,
observable external writes, reservation/application records, receipts, and
conservative unknown states. A zero source-call counter is not the no-execution
oracle. A failed/timeout run remains failure evidence; do not expand watchdogs
or rewrite expectations to turn an unchanged failure green.

* Matched performance manifest
Freeze workload categories for valid answers, no eligible route, policy denial,
unknown send, cancellation, schema failure, config churn and bounded concurrency.
For every run record exact source/tool/config/model/deployment/data identities,
limits, hardware, concurrency, warmup, randomization, repetitions and excluded
contamination. No provider name, price, availability or latest-feature claim is
made by this document.

Compare the inspected agentgateway snapshot on an equal supported subset; name
an unmatched feature explicitly rather than weakening Weaver semantics or
claiming the reference lacks governance. Also compare a static single-binding
Weaver configuration to the configurable route on the same task. Separate
configuration, routing and provider inference costs with instrumentation, while
retaining end-to-end results.

| Measure | Definition / disqualification |
|---------+-------------------------------|
| Quality | Frozen task rubric with independent answer/citation checking; no silent task changes |
| Cost | All accepted inference and routing/judge costs, usage units and unknown holds; no omitted losers |
| Latency | Provider first byte, validated-result latency and end-to-end p50/p95/p99 separately |
| Throughput | Completed schema-valid tasks per time at fixed semantic/fault admission |
| Resources | CPU, memory, buffer/queue high water, bounded rejections and store round trips |
| Churn | Publication-to-effective hard-change acknowledgment, stale denials and recovery time |
| Recovery | Unknown-hold age and manual/automatic reconciliation counts; no timeout refunds |

Scheme compile-once projections, Go cloud-native integration and Rust bounded
execution are benefit hypotheses. Count actual FFI/process crossings, bytes
encoded, durable operations and queue/writer checks before proposing hot-path
optimization. Compiling fewer predicates or winning a model benchmark is not
proof of Gateway speed. Adaptive routing is admitted only after matched ablations
preserve all required semantics and account for every auxiliary model call.

* Explanation and resource contracts
Emit redacted task/node/attempt correlation, profile/package/Policy identity,
eligibility rejection codes, chosen binding, current fence, consumption state,
reservation/unknown state and terminal/application IDs. Do not log raw prompts,
credentials or retrieved documents by default. Bound diagnostic cardinality.

Specify per-tenant queue depth, active requests, normalization expansion and
stream buffer caps before native acceptance. Finite model integers are not a
native overflow proof. Pressure rejects new work before consuming another claim;
capacity pressure does not discard unknown reservations or authorize retries.

* Next research gate
The design contract is reviewable now. Next supply native parity plans with
concrete library/SDK/store candidates and exact effect seams, then decide whether
to implement a bounded prototype. Native implementation remains outside this
turn's authorized design/proof work. RP5 generalization, RP6 retries/resumption
and RP8 adaptive optimization remain deliberately gated.
