The new Lean module imports actual category 13 and 49 modules, not copies of their
theorem names. It constructs the refinement witness and joins profile/schema
identity to actual semantic-use records. Its source-admission theorems use the
existing actual AdmissionBridge and resulting source state. This does not prove
one executable native product joining all those separate transition systems.

The new Quint module invokes the actual existing =RoutineRoutingConfig.dispatch=
and =LlmRouting= transitions; queueing is deliberately separate. Its initial
state assumes one admitted original claim/reservation and pinned finite source
fixture. It does not model the three-node routine interpreter, native parsing,
retrieval, actual response-schema validation, arbitrary ranges or all accounts.
The finite byte cursor represents bounded write opportunities, not a TCP stack.
Natural-number identities and credit bounds are symbolic; they do not certify
native identifier encoding, fixed-width arithmetic or the research workload size.

* Proof premises
- Authentic original capability/context/region template published under the same
  profile commitment, including declared-node-to-logical-source-key membership;
  category 13's registry representation needs that extension.
- Source payload, registry identity, account allocation, package/source closure,
  hard revisions and caller incarnation are authentic current facts.
- Deciding consumption is atomic with its execution record; the transport owner
  honors it and checks fences at the actual write boundary.
- Recovery preserves committed consumption/cursors and retains unknown holds;
  the abstract recover action is not a storage recovery verifier.
- Native codec/name mapping, price/tokenizer bounds and receipt authentication
  satisfy their contracts. Equality of supplied values is not authenticity.
- No liveness under permanent partition or absent usage evidence, no rollback of
  every trusted anchor, and no exactly-once provider delivery are claimed.

* Counterexample controls and retained failures
Six deliberate actions excluded from the safe step expose: sending from queue
without consumption, refunding unknown budget, forgetting execution on restart,
inferring no execution from source-side state, replacing ticket origin, and a
hidden SDK retry. Each must reach a state violating the stated invariant.

The initial Lean draft had a record-update layout error and a reserved local
identifier; a later added rejection theorem needed an explicit node-rule binder.
Failed source/logs are retained. The first Quint draft used an
unexported nested alias. A later test chained an expect after fail and hit
=Variable r not set= in the evaluator. The corrected test separates successful
no-execution safety observation from the subsequent disabled-send control;
it does not weaken the no-execution invariant. Historical draft artifacts remain
under the evidence directory. D2 first rejected locked positions with the dagre
engine; rendering then used the existing TALA layout profile. These are failed proof/harness drafts, not evidence
that a native Gateway was tested or repaired.

The strict-mediation source validates a supplied validation context; callers must
align that context's consumed nonces with authoritative spent state. Its pure
transition is not a persistent concurrent CAS. BoundOperation's own comment
explicitly says equality does not authenticate supplied effect/state. Neither
upstream source is changed, and no new external protocol/version claim is made.
