Lean imports category 51 and its actual category 13/49 ancestors, with a fresh
isolated thirteen-module source rebuild. Twenty-two new declarations print their
axioms without =sorryAx=. The new append-only registry Step is an abstract
publication/binding contract, not a native transaction. Actual-route and semantic
use results compose existing constructors; native publication authenticity is
still an explicit premise.

Quint retains complete ancestor transitions while omitting only their historical
run declarations in the execution bundle. Twenty-four current controls include
twenty guarded/progress/rejection cases and four deliberately unsafe actions.
They cover conflicting publication, replacement binding, lost publication state
and forgotten consumption. Unsafe actions are excluded from the safe step.
Full official type/effect analysis precedes fresh evaluator groups; the typed IR
must remain unchanged. These finite controls are not exhaustive state checking.

* Runtime qualification classification
The native fixture emitted eleven contract check results and actual duplicate-key
rejection, but a natural-exit timeout remains unresolved. Independent controls
and instrumented diagnostics are separate observations. No receipt may promote
the timed workload to a native pass because its final printed marker appeared.
A source rebuild, full compiler/format parity, actual provider wire/SDK behavior,
executor fencing, persistent account/store recovery and measurements remain open.

* Source review and reuse
Recheck the prior sixteen reviewed snapshots by HEAD and working bytes. Also
inspect Core =modules/json-schema/contracts.ss=, =json-schema-source.ss=,
=json-schema-constraints.ss= and =gerbil.pkg= plus the installed Gerbil JSON reader.
The value-contract module explicitly separates value validation from Core
admission; the source module explicitly owns decoding only. Reuse both without
treating them as proof of authenticated publication or durable execution.

POO Flow strict mediation still consumes a supplied validation context; its pure
nonce/root transition is not a persistent CAS. Cedar BoundOperation still checks
supplied effect/state equality and requires host authentication. The full-profile
projection does not remove either boundary. No dependency pin or upstream source
is changed, and no newest-version or external provider feature claim is made.

* Failures retained
The first Lean draft collided with the predefined =id= name and a reserved field
name; its failed source and log are retained. Corrected typed binders compile.
The initial native import failure and natural-exit timeout remain distinct from
successful formal/model checks. Earlier sealed manifests and historical evidence
are preserved, including failed drafts. Receipts do not relabel them as passes.
