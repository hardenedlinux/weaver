* Limits and next boundaries
This checkpoint addresses the bounded native value-contract/JSON check entry
and its resource lifecycle. Native YAML, full common-normal-form/default/diagnostic
parity, genuine profile-content commitment admission, provider SDK semantics,
Rust transport/store fault qualification and Gateway performance remain separate
open work. No Gateway runtime code or dependency pin changes are introduced.
Measured local check durations are acceptance receipts, not an end-to-end Gateway
speedup claim. An assertion/check marker alone remains insufficient everywhere.
