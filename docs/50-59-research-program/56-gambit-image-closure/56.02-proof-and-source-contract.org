* Source comparison and reuse
The original high-level Core/POO closure and eight narrowed stdlib interface/source
builds remain source-bound to the previous qualification. This checkpoint compiles
additional exact lowered Scheme sources rather than claiming a full high-level
Gerbil/Gambit rebuild. Required module/phase units remain present. Original entry
symbols are compared against each original native unit, and all exported native
definitions participate in collision partitioning. A conservative C/FFI-token
filter and native section checks retain their explicit, bounded admission scope.

POO Flow authorized-effect-token and strict-mediation source still own the pure
nonce/root semantics. Their validation context must use authoritative spent-state;
an image identity or a fast native authoring run cannot substitute for it.
cedar-poo-spec BoundOperation and compound authorization still supply operation
binding and semantic composition. Their proofs do not prove Mach-O linking,
Darwin library validation, compiler correctness or a host timing bound.

The existing sixteen reviewed source identities are rechecked, rather than
assuming main or changing dependency pins. The current native image manifest
refines the local execution profile, not the original task/claim/budget/history
identity. Source review currentness and compiled-input identity are distinct
checks and are reported separately.

* Scheme, Go and Rust
Scheme owns the defining Contract, original binding owners, module/phase identities,
required initializer closure and configuration meaning. Image aliases preserve
those identities. Compilation and first-use qualification stay outside the final
provider hot path; this research introduces no per-request compiler or Gateway.

Go owns cloud native reconciliation, lifecycle publication and typed proposals.
It must consume the completed source-bound qualification result. A progress file,
collector exit zero, warm pass or image UUID cannot promote a failed required
first-use series or issue a new task family. provider-client retries remain proposals subject
to the original claim, reservation and history constraints.

Rust owns the designed final broker/executor checks: current source, owner fence,
Cedar Policy, history and budget/claim joins remain necessary at actual dispatch.
Native qualification is evidence about a source-bound authoring profile, not a
capability for transport or a replacement for final compare-and-consume.

* Quint controls and actual counterexamples
[[file:../../../dev/proofs/quint/GambitLocatorClosure.qnt][GambitLocatorClosure]] checks distinct handles with equal entry names, duplicate
entry rejection within an image, incomplete producer refusal, foreign-body refusal,
entry rewriting, wrong-handle lookup, requested-owner initialization, mapping
without eager initialization and closed/duplicate initialization rejection.
Deliberate collision admission, missing completion and bare-name wrong-owner lookup
provide counterexamples. The native two-module probe exercises the handle premise
rather than relying only on an abstract model that assumes it.

The official parse/type/effect/test pipeline checks finite named controls. The
Lean imported closure supplies arbitrary finite custody and failed-receipt
retention under its stated transition premises. Neither is exhaustive native
interleaving testing, a C compiler proof, an OS proof or a performance theorem.
All current receipts and historical failures retain their original verdicts.

* Execution-profile changes do not replace the original semantic contract
Image grouping and native artifact bytes change the execution-profile digest.
That profile requires its own qualification; it cannot reuse an older native
receipt merely because module names or high-level sources agree. The original
semantic task, claim, profile commitment, reservation and history identities do
not reset when files, UUIDs or handles change.

If an existing authority binds the old execution digest, the new profile cannot
consume that authority through an equivalence assertion. It must pass the normal
authoritative source/profile publication and final join rules while preserving
the original claim, budget, history and pending outcomes. This research supplies
qualification evidence only; it neither activates a registry profile nor issues,
consumes or migrates a Gateway grant. The imported actual-dispatch proof keeps
the current final Policy and wire guards necessary in every case.

* Same entry is insufficient without the committed source
The final locator model separates a proposed manifest source digest from the
external authoritative source commitment. Qualified handle uniqueness alone is
not source authority. Replacing the source while retaining the same entry must
reject publication. The new source-bound resolution theorem preserves the
committed module digest; composition with the semantic Contract proves that the
native owner remains the original required binding owner. A separate Quint
source-replacement rejection and deliberate bypass trace check this missing
assumption directly. The native artifact audit compares original/source snapshot,
object and per-alias source records, under the stated trusted compiler/builder
and authoritative-baseline premises.
