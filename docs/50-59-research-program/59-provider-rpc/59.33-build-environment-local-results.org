* Remote CI boundary and retained evidence
PR workflow [[https://github.com/hardenedlinux/weaver/actions/runs/41074924436][41074924436]] did not start any test step. GitHub rejected all seven
jobs with an account payment or spending-limit annotation. It did recognize
the requested =ubuntu-latest= and =macos-latest= labels. This is an external
account restriction, not a passing CI result or a source assertion failure.
Organization administration must resolve it before exact-PR remote checks can
execute. No billing setting, permission, dependency pin or timeout was changed
to hide that restriction.

The fixed ignored results are =latest-scheme-startup.json= and
=latest-check-scheme.json= under =.cache/verification/=. Native traces, generated
package metadata, preparation prefixes and build logs are temporary and cleaned
after verification. Curated English Org evidence is committed; raw logs are
not added to Git. The PR is complete for code review with the remote CI
restriction stated explicitly; it is not merged by this qualification.
