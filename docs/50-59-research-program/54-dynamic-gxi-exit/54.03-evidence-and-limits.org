* Limits
This is a bounded workload qualification for the ordinary interpreter with an
isolated import-narrowed stdlib, not a global installation or an OS-wide dyld
repair. Import-boundary admission depends on stable binding owners, required initializers
and unchanged executable bodies; arbitrary import removal cannot use its argument. General plugin lifetimes,
all possible destructor behavior, full YAML/default/normalization parity and actual
Gateway transport/store fault handling remain separate work. Local timing is not
a universal performance SLA. Dependency pins and Gateway implementation stay unchanged.

* Retained controls and observation defects
The first observer request through the installed bash launcher did not create
an observer receipt: the protected shell stripped the insertion environment.
That run proves only its native gate and LU, not reference-counter coverage.
Later observed runs invoke the exact same installed interpreter executable with
its launcher's runtime-root settings and a verification observer. Ordinary
launcher and exact-original-script runs remain separately qualified.

The first freshly linked same-object unbatched control exceeded the deadline and
was still running when its diagnostic observer returned at forty seconds. That
is a failed gate with unknown original exit status, not a forty-second budget.
Later cleanup counters were balanced and an own-PID check found the process gone;
its unreaped exit code remains unknown. The initial alternating batch may overlap
that overdue process and is not a quiet-host timing experiment. The subsequent
quiet batch starts after the process-absence check. Future diagnostic controllers
retain the child until natural termination while keeping the fifteen-second
acceptance verdict fixed.

The quiet alternating batch retained packed timings of 4.922 and 5.501 seconds,
and same-object unbatched timings of 5.719 and 7.562 seconds. All four passed and
closed all 261 tracked references. The direct evidence for image work reduction
is 307 versus 216 peak images; these few local timings establish no general
speedup ratio or elimination of host notification variability.
