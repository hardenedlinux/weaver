#+TITLE: Protobuf and optional Arrow serialization
#+LANGUAGE: en

* Workload

Equivalent one-event and thirty-two-event workloads encoded as Protobuf frames or actual Arrow IPC batches.
Four encoding cases and one source certificate/SPKI identity case belong to this
package in the all-features matrix. The fifth case measures bounded DER parsing
and digest derivation, not a TLS handshake, CA validation or key possession.

* Measurement boundary

Frame construction and serialization. Record throughput is reported; compare normalized record cost as well as batch latency. Arrow requires the arrow feature. Go integration benchmarks separately measure warm mTLS RPC, reconnect and source publication.

* Entrypoints

Run this package with =cargo bench -p weaver-server --all-features --bench gateway --locked --offline -- --noplot=.
Run the complete measured matrix with =go run ./go/cmd/weaver-dev bench=.
Criterion is inherited from the workspace as a development dependency.
Each case uses thirty samples, one second of warm-up and two seconds of requested measurement.
Compilation or a smoke invocation alone is not a measured baseline.

The Go runner retains environment logs, source hashes, fresh per-case Criterion
data and an English Org summary. Missing cases fail artifact collection.
Regression warnings remain evidence even when the benchmark process succeeds;
these measurements do not establish a production latency or throughput target.

See [[file:../../../docs/50-59-research-program/59-provider-rpc/59.05-benchmarks.org][the workspace benchmark contract]] for the complete matrix and interpretation rules.

* Preparation placement and deciding holding

=server/encoding_guard_hold/{inside,outside}= uses the same optimized benchmark
image, exact 32-row/4096-byte-per-row Arrow payload, original ledger fixture and
fresh per-row Cedar guard in both arms. The reference arm encodes inside the
queue callback; the current-placement arm owns the encoded frame before entry.
Both assert byte-identical frames and retain the same original held budget.
This is an adversarial bounded encoder workload, not a measured LLM token stream.

Criterion iter_custom reports the session's observed transaction-hold duration
for the single final release, including guard/commit handling. It excludes lock
acquisition, preparation outside that scope, fixture creation and teardown. The
reported unit is therefore guarded holding nanoseconds, not whole-operation
elapsed latency. All thirty samples per arm are retained. The arms run as normal
Criterion cases in one image; host drift can affect differences, and this is not
a balanced end-to-end old/new application experiment. The separate six-block
ABBA lock experiment measures contention sensitivity.
