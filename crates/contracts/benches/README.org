#+TITLE: Request and publication commitments
#+LANGUAGE: en

* Workload

Provider request commitments for 128 B, 16 KiB and 512 KiB source payloads; publication commitment for a 16 KiB Policy comment and typed schema.
Immutable provider profile commitment and closed request validation at the same
three payload sizes. Exact review evidence commitment adds a ninth case, using
a bounded immutable upstream artifact. It measures hashing, not Delta approval.
Source handoff commitment adds the tenth case, binding the original operation,
expected epoch, actual certificate/SPKI and role-credential digests.

* Measurement boundary

Canonical hashing and commitment construction. Fixtures are created before timing; byte throughput is reported. This does not measure network transport.
Profile validation includes duplicate-aware decoding, closed fields, message and
sampling checks; profile hashing includes all semantic limits. The input bodies
are valid text requests; this is not an adversarial-parser throughput claim.

* Entrypoints

Run this package with =cargo bench -p weaver-contracts --all-features --bench gateway --locked --offline -- --noplot=.
Run the complete measured matrix with =go run ./go/cmd/weaver-dev bench=.
Criterion is inherited from the workspace as a development dependency.
Each case uses thirty samples, one second of warm-up and two seconds of requested measurement.
Compilation or a smoke invocation alone is not a measured baseline.

The Go runner retains environment logs, source hashes, fresh per-case Criterion
data and an English Org summary. Missing cases fail artifact collection.
Regression warnings remain evidence even when the benchmark process succeeds;
these measurements do not establish a production latency or throughput target.
