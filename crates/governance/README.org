#+TITLE: Typed Governance Source Ownership
#+LANGUAGE: en

=SourceData= is concrete source data. =OwnedSource::from_source= validates original
Governor selection and task/plan/profile commitments. Neither grants publication,
execution or budget-release authority. JSON/YAML file decoding stays with Go.

With =scheme-vm=, =materialize_source= consumes an SDK strong root and converts
native tables/vectors, strings and exact integers directly to Rust-owned records.
There is no whole-record JSON encoding, dynamic application Any or retained VM
pointer. Struct fields use symbol keys and identifier maps use string keys.
=root_source= constructs the reverse direction with the same SDK: concrete
validated records become rooted native values on the owner thread. Strings are
UTF-8 length-delimited data, including embedded NUL, and integers use exact binary
magnitude. Constructors return =SourceError=; they do not panic on SDK failure.
Cumulative string/key bytes and node visits plus collection bounds limit each
construction. Partial failure drops intermediate owned roots naturally. These
are traversal bounds, not a bound on the VM heap or hostile producer allocation.

The production library forbids unsafe code. =scheme-vm= exposes only conversion;
=scheme-qualification= additionally links the test-only program graph. The optional integration fixture binds
one approved linked program/export in its own documented ABI module, exercises
the actual AA/Governor/Cedar composition and cleans the VM before reading owned
results. It requires explicit =GERBIL_HOME=, =GERBIL_PATH=, =GERBIL_LOADPATH= and
=WEAVER_CONTROL_SCHEME_COMPILER= for the approved isolated SDK/source prefix.
The selected SDK's capacity must be reported separately from host core count.

=cargo test -p weaver-governance --features scheme-qualification --locked --offline=.

The existing Go process/file adapter is still an open production embedding owner.
This crate does not silently substitute for that adapter or authorize an alternate
runtime path. Benchmark boundaries live in =benches/README.org=.

=OwnedSource= proves candidate consistency only. Production-host content admission
uses =SourceExpectation::capture= on the independently admitted original before
calling Scheme, then =materialize_bound_source= or =bind=. The resulting
=BoundSource= preserves the entire original artifact and remains data. Capturing
an expectation from the candidate is not original admission. Registry/callback
authenticity and current Policy/history/fence/ledger checks remain mandatory.

=ProducerCatalog= seals up to 64 host-approved names with immutable originals and
source-authority identity/epoch bindings. Aggregate UTF-8 data/key text plus names
must fit =MAX_SOURCE_BYTES=; native traversal bounds remain separate. Duplicate
families/names and conflicting publication IDs refuse. =ProducerClient= selects
only a registered name and compares the full source observation before queueing
its original. A supplied observation is not proof of current authority: the RPC
owner must derive and recheck actual authenticated source state. Catalog lookup
does not publish, send, consume, settle or authenticate a compiler.

=OwnedSource= shares private immutable concrete data. No mutable/interior-mutable
view is exposed, so retaining the original cannot follow changes to a caller's
replacement handle or the Scheme object graph. It avoids copying/parsing each
body again at admission; returned candidates still undergo complete record equality.
=GovernanceWorker::publish_producers= installs one set for its initialized compiler
through the shared runtime gate. Updates/recovery of authoritative registry state
and production compilation RPC remain separate, unqualified work.

=source_lane= supplies bounded =SourceClient=/=SourceInbox= ownership. The existing
server runtime must track the blocking owner and construct its non-Send Scheme
VM there. No VM or rooted Scheme object crosses the queue. Only concrete owned
input and original-bound output cross it. Queued, active and unread ready replies
retain capacity; cancelling active work waits for natural foreign-call return
before releasing its slot. Close is terminal and fences final future delivery,
including an already-ready result. Close acknowledgment is not owner drain or
VM cleanup acknowledgment. The embedding runtime must join the owner after
natural cleanup. This primitive does not install an approved producer registry,
replace the Go file adapter, publish Policy, send, or release unknown budget.

The server's existing =ServiceRuntime::start_governance= now supplies that
tracked owner. Its Send factory constructs a non-Send compiler on the worker;
shared shutdown closes source delivery and shared drain waits for VM cleanup.
=serve_grpc_with_runtime= permits the same owner to serve authenticated RPC.
An embedding error or abandoned service future closes admission; the caller
still needs drain for cleanup acknowledgment. The actual approved SDK graph is
qualified by the server's opt-in =governance-qualification= integration target.
That test capability does not install the production producer registry or an RPC
that accepts arbitrary source modules, paths or callback addresses.
