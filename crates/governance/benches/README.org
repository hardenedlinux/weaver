* Workload

Clone concrete source records and check original selection/profile/plan bindings.

* Measurement boundary

This includes existing body/profile commitment validation. It excludes VM startup,
AA execution, SDK root conversion, gRPC and provider sends. It is not native VM
acceptance or Gateway throughput. Thirty samples use existing collection settings.

* Entrypoints
